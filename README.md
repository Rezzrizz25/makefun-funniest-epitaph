Entry for the make.fun bounty **Famous Last Words: The Funniest Epitaph** — a single-line tombstone epitaph of 150 characters or fewer, judged blind by an AI graveyard judge on which line gets the biggest laugh.

> Here lies Dave. He died doing what he loved: ignoring the warning labels.

## Run it

```sh
node main.ts
```

Writes the epitaph to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`), enforcing the gate: a single non-blank line of 1–150 characters.
